# Changelog

Player-facing changes of each published release, newest first.

## 0.9.0 (2026-11-22)

### Initial release

First release of Grenade.

- Right-click to throw the Grenade in a slow, visible arc. It explodes a moment after it lands, with a green puff, and works underwater too.
- The blast hurts creatures within about 6 blocks, less with distance and behind cover. It does not break blocks, start fires or destroy items on the ground. It hurts you too if you stand too close.
- Craft it in a crafting table with four copper nuggets and one gunpowder, placed in a plus shape with the gunpowder in the middle. It stacks to 16, has a short cooldown between throws, and dispensers can fire it.
